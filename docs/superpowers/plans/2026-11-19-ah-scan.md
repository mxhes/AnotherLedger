# LootLedger scan Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** LootLedger reads the auction house itself (full scan plus passive search results) when neither TSM nor Auctionator is loaded, and offers those prices as the price source "LootLedger scan".

**Architecture:** A pure `Scan.lua` holds the math (market value / lowest, time-weighted daily average), the packed storage and a chunked reader with injected client calls. `Sources/Scan.lua` registers the source after Auctionator. Core wires the auction house events, the 15-minute wait, the reminder and `/ll scan`; `UI/ScanButton.lua` puts the button on the auction house window.

**Tech Stack:** Lua 5.1 WoW addon, plain-Lua tests (`lua tests/run.lua`).

**Spec:** `docs/superpowers/specs/2026-11-19-ah-scan-design.md`

## Global Constraints

- Lua 5.1 only: no `goto`, `//`, `table.unpack`, integer-only APIs. Run `lua tests/run.lua` after every task; all tests pass.
- Files outside `UI/` are pure: client calls are injected or looked up at call time. `UI/` files touch globals only inside functions.
- Every text through `ns.L` (`local L_X = L["Text"]` at file top), German in `Locales/deDE.lua`; remove the German entry of any English text you change.
- Options: default in `DB.defaults.settings`, label at most 24 characters, a tooltip.
- New `.lua` file: add to `LootLedger/LootLedger.toc` and the layout table of `docs/DEVELOPMENT.md`.
- Every unconfirmed client API: `-- UNVERIFIED (check in client)` comment plus a line in `docs/CHECKLIST.md`.
- Edit Lua with the Write / Edit tools (Git Bash heredocs and sed strip backslashes).
- Commits: `feat:` / `fix:` / `docs:` one-line summary plus short body, ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Spec values: wait 15 min (`Scan.WAIT = 900`), refusal timeout 60 s, market = cheapest 15% of units (at least one), half-life 5 days, max age 14 days, reminder after 24 h, battle pet cage item ID 82800 skipped, entries without buyout skipped.

## Review Focus

1. **A key with one huge stack** (one auction of 200 units at 1c among ten of 1 unit at 50g): the cheapest 15% is counted in units, so the market value is 1c, not an average of auctions. Test in Task 1.
2. **Two scans the same day, the second missing an item**: the first scan's value for it stays (no data is not zero). Test in Task 2.
3. **Long gap** (last value 10 days old, new scan today): today's value must dominate (weight of the old average 0.5^(10/5) = 0.25). Test in Task 2.
4. **Auction house closed mid-read**: the reader stops, commits what it aggregated, prints the stopped line once, and a later `REPLICATE_ITEM_LIST_UPDATE` does nothing. Test in Task 5.
5. **TSM loads after scan prices exist**: scan button absent, passive recording off, but the saved scan prices still answer when the player picks "LootLedger scan". Test in Task 5.

### Task 2: Daily average and packed storage

**Files:**
- Modify: `LootLedger/Scan.lua`
- Test: `tests/test_scan.lua`

**Interfaces:**
- Produces:
  - `Scan.DAY = 86400`, `Scan.HALF_LIFE_DAYS = 5`, `Scan.MAX_AGE = 14 * 86400`.
  - `Scan.pack(e) -> string`, `Scan.unpack(s) -> e or nil`; `e = { t, m, l, am, al, ad }` (t = seconds of the newest value; m / l today's market / lowest; am / al / ad the running average of the days before and its day number, all optional together). Base-36 integers joined by `,`; malformed text -> nil.
  - `Scan.record(items, key, market, lowest, now)`: `items[key]` packed. Same day as `e.t` -> replace m, l, t. Later day -> fold the old day into the average first: no average yet -> `am, al, ad = m, l, day(t)`; else `w = 0.5 ^ ((day(t) - ad) / HALF_LIFE_DAYS)`, `am = am*w + m*(1-w)` (same for al), `ad = day(t)`; then set the new m, l, t. Values rounded down to copper.
  - `Scan.price(items, key, kind, now) -> copper, ageSeconds` (`kind` = `"market"` or `"lowest"`): nil when missing, unreadable or `now - t > MAX_AGE`. With an average: `w = 0.5 ^ ((day(t) - ad) / HALF_LIFE_DAYS)`, price = `floor(avg*w + today*(1-w))`; without: today's value.
  - `Scan.prune(items, now) -> removed` (drops unreadable and too-old entries).
  - `Scan.lookup(items, itemID, link, kind, now) -> copper, age`: the `LootParse.itemKey(link)` entry, else the `itemID` entry.
